================================================================================
PAQ9 CUDA / C++23 Compilation, Compression, and Decompression Instructions
================================================================================

1. HOW TO COMPILE WITH C++23
--------------------------------------------------------------------------------
For CUDA (nvcc):
    nvcc -std=c++23 -O3 paq9-cuda.cu -o paq9-cuda

    Alternative (explicitly setting C++23 for both host and device):
    nvcc -std=c++23 -Xcompiler -std=c++23 -O3 paq9-cuda.cu -o paq9-cuda

For Standard C++ (GCC / Clang):
    g++ -std=c++23 -O3 main.cpp -o main
    clang++ -std=c++23 -O3 main.cpp -o main


2. HOW TO COMPRESS USING CLI
--------------------------------------------------------------------------------
Command Format:
    ./paq9-cuda -c <destination_archive> -<level> <source_file>

Arguments:
    -c                    Flag specifying compression mode.
    <destination_archive> Output filename for the compressed archive (e.g., file.paq9).
    -<level>              Compression level as an integer flag (e.g., -1, -2, ..., -9).
    <source_file>         The uncompressed input file to compress.

Example:
    ./paq9-cuda -c compressed.paq9 -1 input.txt


3. HOW TO DECOMPRESS USING CLI
--------------------------------------------------------------------------------
Command Format:
    ./paq9-cuda -d <source_archive> <destination_output>

Arguments:
    -d                    Flag specifying decompression mode.
    <source_archive>      The compressed archive file to decompress (e.g., compressed.paq9).
    <destination_output>  Filename for the extracted/decompressed output file.

Example:
    ./paq9-cuda -d compressed.paq9 output.txt


4. VERIFYING INTEGRITY
--------------------------------------------------------------------------------
To verify that the decompressed file matches the original input:

    diff input.txt output.txt

Or use the comparison script:

    python3 compare.py
